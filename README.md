Analysis of USA regional sales data to identify sales trends,
top-performing products, and regional performance.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter/Google Colab

## Key Analysis
- Regional sales performance
- Product-wise revenue
- Monthly sales trends
- Customer analysis

## Conclusion
Insights derived from the dataset to support better business decisions.
